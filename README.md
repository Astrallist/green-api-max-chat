# Интерфейс для GREEN-API (мессенжер MAX)

Реализован пользовательский интерфейс для отправки и получения сообщений в мессенджере MAX через сервис GREEN-API.

## Технологии
- React (Vite)
- TypeScript
- Axios (для запросов к API)
- Чистый CSS (без сторонних библиотек)

## Как запустить локально
1. Клонируйте репозиторий.
2. Установите зависимости: `npm install`
3. Запустите проект: `npm run dev`
4. Откройте `http://localhost:5173`

## Как пользоваться
1. Введите ваши `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API.
2. Введите номер телефона или `chatId` получателя для создания чата.
3. Отправляйте сообщения и получайте ответы в реальном времени (Long Polling).
